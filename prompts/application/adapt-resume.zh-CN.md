# 适配简历提示

仅使用已验证的候选人证据，选择并准备最合适的简历以匹配一份职位发布。

<a id="read-before-starting"></a>
## 开始前请阅读

1. `AGENTS.md`
2. 完整的职位发布内容
3. 已验证的候选人证据
4. 现有简历变体及其实际内容
5. 简历格式和长度限制

<a id="decision"></a>
## 决策

选择 exactly 一个操作：

- **复用** - 已有的简历已足够契合，无需实质性修改。
- **适配** - 已有的简历可作为基础，但需调整重点、顺序或措辞。
- **创建** - 不存在任何足够合适的现有简历作为基础。

优先选择 `REUSE`，然后是 `ADAPT`，当它们准确代表证据时。不要仅仅因为措辞不同就创建新变体。

<a id="rules"></a>
## 规则

- 需将职位职责与要求与简历内容进行对比，而非仅依据文件名或变体标签。
- 不得虚构任何技能、经验、项目角色、成果、日期或指标。
- 不得将相关经验转化为精确经验。
- 在缩短或重新表述证据时，必须保持事实含义不变。
- 优先保留相关证据，并仅移除为满足格式限制而必需的低价值内容。
- 保持措辞对招聘人员可读，并具体到足以验证的程度。
- 记录重要未支持的要求，而非将其插入简历中。
- 保留原始简历或模板。当需要修改时，将适配后的输出写入单独的目标文件。

<a id="output"></a>
## 输出

提供：

1. `REUSE`、`ADAPT` 或 `CREATE`；
2. 选定的基线简历（如有）；
3. 基于证据的说明理由；
4. 需要强调、重新排序、重写或省略的内容；
5. 必须避免声称的重要空白点；
6. 当请求创建新文档时，提供目标文件；
7. 对事实准确性、格式和可读性执行的检查。

候选人将在最终简历使用前进行审核。
