# Update Project Documentation Prompt

Inspect the implementation and existing technical documentation.

Update the documentation so that it reflects the current repository state.

## Rules

- Make the smallest useful changes.
- Preserve valid existing content.
- Prefer additions over unnecessary rewrites.
- Document abandoned approaches only when they provide useful context.
- Never document functionality that is not present in the repository.
- Clearly distinguish current behavior from future work.
- Keep terminology consistent with the codebase.
- Preserve useful historical results when they remain relevant.
- Remove outdated instructions that could mislead a contributor.

## Check

Review:

- architecture;
- workflows;
- configuration;
- CLI usage;
- tests;
- known issues;
- evaluation results;
- current milestone;
- next milestone.

## Output

Modify only the relevant documentation files.

Provide a concise change summary.
