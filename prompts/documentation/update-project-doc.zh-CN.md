# 更新项目文档提示

检查实现和现有的技术文档。

更新文档以反映当前仓库状态。

<a id="rules"></a>
## 规则

- 只做最小的有用变更。
- 保留有效的现有内容。
- 优先添加而非不必要的重写。
- 仅在提供有用上下文时，记录已废弃的方案。
- 绝不记录在仓库中不存在的功能。
- 明确区分当前行为与未来工作。
- 保持术语与代码库一致。
- 在仍具相关性时，保留有用的歷史结果。
- 移除过时的说明，以免误导贡献者。

<a id="check"></a>
## 检查

审查：

- 架构；
- 工作流；
- 配置；
- 命令行使用方式；
- 测试；
- 已知问题；
- 评估结果；
- 当前里程碑；
- 下一个里程碑。

<a id="output"></a>
## 输出

仅修改相关的文档文件。

提供简洁的变更摘要。
