# Mettre à jour le prompt README

Examinez le référentiel et mettez à jour son README afin qu'il reflète l'état actuel du projet.

<a id="review"></a>
## Vérification

Vérifiez :

- l'objectif du projet ;
- l'état actuel ;
- les fonctionnalités implémentées ;
- les instructions de mise en place ;
- les commandes d'utilisation ;
- un résumé de l'architecture ;
- les tests ;
- les benchmarks ou les résultats ;
- la roadmap ;
- les limitations connues.

<a id="rules"></a>
## Règles

- Vérifiez les affirmations en fonction du référentiel.
- Conservez le contenu valide existant.
- Préférez des modifications minimales.
- Préférez les ajouts plutôt que des réécritures inutiles.
- Ne documentez pas les fonctionnalités non implémentées.
- Séparez clairement les travaux futurs des fonctionnalités actuelles.
- Supprimez les commandes ou instructions périmées.
- Ne faites pas grossir la description du projet.

<a id="output"></a>
## Sortie

Mettez à jour le README en place.

Après la mise à jour, résumez :

- les sections modifiées ;
- les affirmations obsolètes corrigées ;
- nouvelles informations ajoutées.
