# Update README Prompt

Inspect the repository and update its README so that it reflects the current project state.

## Review

Check:

- project purpose;
- current status;
- implemented features;
- setup instructions;
- usage commands;
- architecture summary;
- tests;
- benchmarks or results;
- roadmap;
- known limitations.

## Rules

- Verify claims against the repository.
- Preserve valid existing content.
- Prefer minimal diffs.
- Prefer additions over unnecessary rewrites.
- Do not document features that are not implemented.
- Keep future work clearly separated from current functionality.
- Remove stale commands or instructions.
- Do not inflate the project description.

## Output

Update the README in place.

After the update, summarize:

- sections changed;
- outdated claims corrected;
- new information added.
