# 更新 README 提示

检查仓库并更新其 README，使其反映项目的当前状态。

<a id="review"></a>
## 审查

检查：

- 项目目的；
- 当前状态；
- 已实现的功能；
- 设置说明；
- 使用命令；
- 架构概要；
- 测试；
- 基准测试或结果；
- 路线图；
- 已知限制。

<a id="rules"></a>
## 规则

- 将声明与仓库内容进行核对。
- 保留现有有效内容。
- 优先采用最小差异。
- 优先添加内容而非不必要的重写。
- 不要描述尚未实现的功能。
- 将未来工作与当前功能明确区分开来。
- 移除过时的命令或说明。
- 不要夸大项目描述。

<a id="output"></a>
## 输出

原地更新 README。

更新后总结：

- 修改的章节；
- 过时的声明已更正；
- 新增信息。
