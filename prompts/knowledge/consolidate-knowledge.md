# Consolidate Knowledge Prompt

Review the requested area of the knowledge base and consolidate overlapping or fragmented information.

## Objective

Improve structure without losing useful technical detail.

Identify:

- duplicated notes;
- fragmented explanations;
- inconsistent terminology;
- stale information;
- weakly linked related concepts;
- unnecessary files;
- notes that should be merged;
- notes that should remain separate.

## Rules

- Prefer improving an existing note over creating a duplicate.
- Preserve useful examples and technical detail.
- Do not merge concepts only because they are related.
- Assign one responsible note to each concept or precise result.
- Keep project-specific facts, full metrics, and historical experiments in their source records; link to them instead of copying them across concepts.
- Maintain existing valid links.
- Preserve provenance and evidence status when moving or condensing information.
- Avoid large-scale restructuring unless there is a clear benefit.
- Prefer minimal structural change.

## Output

Provide:

1. proposed merges;
2. proposed updates;
3. proposed deletions or archives;
4. cross-links to add;
5. terminology to standardize.

If file modifications are requested, apply the smallest useful set of changes.
