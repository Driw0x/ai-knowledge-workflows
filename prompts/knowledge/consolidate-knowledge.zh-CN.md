# 知识整合提示

审查知识库中的请求区域，并整合重复或碎片化的信息。

<a id="objective"></a>
## 目标

在不丢失有用技术细节的前提下，优化结构。

识别：

- 重复的笔记；
- 碎片化的解释；
- 术语不一致；
- 过时的信息；
- 关联概念之间连接薄弱；
- 不必要的文件；
- 应合并的笔记；
- 应保持独立的笔记。

<a id="rules"></a>
## 规则

- 优先改进现有笔记，而非创建重复笔记。
- 保留有用的示例和技术细节。
- 不要仅仅因为概念相关就进行合并。
- 为每个概念或精确结果指定一个负责的笔记。
- 保持项目特定的事实、完整指标和历史实验在其原始记录中；通过链接指向它们，而不是在不同概念间复制。
- 维持现有的有效链接。
- 在移动或压缩信息时，保留其来源和证据状态。
- 除非有明确的益处，否则避免大规模结构调整。
- 优先采用最小的结构变更。

<a id="output"></a>
## 输出

提供：

1. 建议合并的内容；
2. 建议更新的内容；
3. 建议删除或归档的内容；
4. 需要新增的交叉链接；
5. 需要标准化的术语。

如果请求文件修改，应用最小且实用的变更集。
