# Evaluate Project Prompt

Evaluate the project as evidence for the candidate's target technical roles.

## Read before starting

1. `AGENTS.md`
2. The project repository
3. Existing project documentation
4. Relevant career profile or target-role definitions, if available

## Evaluation dimensions

Assess:

- technical depth;
- implementation maturity;
- practical relevance;
- originality;
- reproducibility;
- testing quality;
- documentation quality;
- measurable results;
- portfolio value;
- interview value;
- alignment with target roles.

## Skill evidence

For every important skill, classify the evidence as:

- **Strong**
- **Moderate**
- **Weak**
- **Unsupported**

Explain the evidence behind each classification.

## Decision

Recommend one of:

- **Continue**
- **Strengthen before showcasing**
- **Showcase now**
- **Pause**
- **Archive**

## Output

Include:

1. project summary;
2. strongest demonstrated skills;
3. weaknesses or missing evidence;
4. best-fit role families;
5. highest-value next milestone;
6. final recommendation.

Do not reward complexity for its own sake.

Prefer improvements that increase real evidence, usability, reproducibility, or relevance.
