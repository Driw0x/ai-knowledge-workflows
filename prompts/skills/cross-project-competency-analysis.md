# Cross-Project Competency Analysis Prompt

Analyze the candidate's projects collectively to determine which competencies are strongly demonstrated across the portfolio.

## Read before starting

1. `AGENTS.md`
2. Relevant project profiles
3. Relevant skill records
4. The candidate's career profile, if available

## Objective

Evaluate competencies across multiple projects rather than project by project.

Identify:

- competencies demonstrated by several independent projects;
- competencies demonstrated strongly by only one project;
- competencies with weak or indirect evidence;
- competencies that are unsupported;
- redundant project evidence;
- gaps across the overall project portfolio;
- the strongest project evidence for each target role family.

## Evidence rules

A competency is stronger when it is supported by:

- multiple independent projects;
- substantial implementation depth;
- tests or benchmarks;
- repeated use in different contexts;
- measurable results;
- clear technical documentation.

Do not automatically rate a competency as strong because it appears in several project descriptions.

Repeated weak evidence does not equal strong evidence.

## Classification

For each competency, assign one of:

- **Strong and distributed** — strong evidence across several projects
- **Strong but concentrated** — strong evidence, but mainly from one project
- **Moderate** — clear evidence with limited depth or breadth
- **Weak** — minimal or indirect evidence
- **Unsupported** — no reliable evidence

## Analysis

Produce a table with:

| Competency | Supporting projects | Evidence summary | Coverage |
|---|---|---|---|
|  |  |  | Strong and distributed / Strong but concentrated / Moderate / Weak / Unsupported |

Then identify:

### Cross-project strengths

Competencies supported by several projects and useful across multiple target roles.

### Concentrated strengths

Competencies demonstrated well, but dependent on one main project.

### Portfolio redundancies

Projects that demonstrate nearly the same competencies without adding much new evidence.

### Portfolio gaps

Important competencies that are missing or only weakly demonstrated.

### Best proof projects

For each target role family, identify the strongest one or two projects to use as evidence.

## Recommendations

Recommend:

- which projects should remain prominent;
- which projects should be strengthened;
- which missing competencies would add the most portfolio value;
- where a new project is justified;
- where an existing project should be improved instead of creating a new one.

Do not recommend new projects merely to increase project count.

Prefer improvements that broaden or deepen the evidence base.

## Output

Return:

1. competency matrix;
2. cross-project strengths;
3. concentrated strengths;
4. redundancies;
5. portfolio gaps;
6. best proof projects by role family;
7. prioritized recommendations.

Do not modify source files unless explicitly requested.
