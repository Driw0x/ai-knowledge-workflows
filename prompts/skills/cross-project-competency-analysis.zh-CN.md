# 跨项目能力分析提示

综合分析候选人的项目组合，以确定哪些能力在多个项目中得到显著体现。

<a id="read-before-starting"></a>
## 开始前请先阅读

1. `AGENTS.md`
2. 相关项目档案
3. 相关技能记录
4. 若可获得，候选人的职业履历

<a id="objective"></a>
## 目标

应从多个项目整体出发评估能力，而非逐个项目分析。

识别：

- 由多个独立项目共同体现的能力；
- 仅由单一项目显著体现的能力；
- 证据薄弱或间接体现的能力；
- 未得到支持的能力；
- 项目证据重复冗余的部分；
- 整体项目组合中存在的能力缺口；
- 每个目标职位家族中最强有力的项目证据。

<a id="evidence-rules"></a>
## 证据规则

当一项能力得到以下支持时，其强度会增强：

- 多个独立项目的支持；
- 实质性的实现深度；
- 测试或基准评估；
- 在不同情境下的重复使用；
- 可量化的成果；
- 清晰的技术文档支持。

不要仅仅因为一项能力出现在多个项目描述中，就自动将其评定为强证据。

重复的弱证据并不等于强证据。

<a id="classification"></a>
## 分类

对每一项能力，分配以下其中一项：

- **广泛且有力** - 在多个项目中拥有强有力证据
- **有力但集中** - 证据有力，但主要来自单一项目
- **中等** - 有明确证据，但深度或广度有限
- **薄弱** - 证据极少或间接
- **未支持** - 无可靠证据

<a id="analysis"></a>
## 分析

生成一个表格，包含：

|能力|支持项目|证据摘要|覆盖范围|
|---|---|---|---|
|  |  |  |广泛且有力 / 有力但集中 / 中等 / 薄弱 / 未支持|

然后识别：

<a id="cross-project-strengths"></a>
### 跨项目优势

由多个项目共同体现且对多个目标职位均适用的能力。

<a id="concentrated-strengths"></a>
### 集中优势

在单一主要项目中表现优异，但依赖该项目的能力。

<a id="portfolio-redundancies"></a>
### 项目冗余

多个项目体现几乎相同能力，未增加新证据。

<a id="portfolio-gaps"></a>
### 项目缺口

重要能力缺失或仅弱体现。

<a id="best-proof-projects"></a>
### 最佳证明项目

针对每个目标职位家族，确定最强或最有力的1至2个项目作为证据。

<a id="recommendations"></a>
## 建议

建议：

- 哪些项目应保持突出地位；
- 哪些项目应加强其内容；
- 哪些缺失能力将为项目组合带来最大价值；
- 在何处开展新项目是合理的。
- 在现有项目上进行改进，而不是创建新项目。

不要仅仅为了增加项目数量而推荐新项目。

优先选择能够扩大或深化证据基础的改进措施。

<a id="output"></a>
## 输出

返回：

1. 能力矩阵；
2. 跨项目优势；
3. 集中优势；
4. 冗余项；
5. 组合缺口；
6. 按角色家族划分的最佳证明项目；
7. 优先推荐事项。
