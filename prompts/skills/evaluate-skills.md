# Evaluate Demonstrated Skills Prompt

Inspect the available evidence and determine which skills are actually demonstrated.

## Evidence sources

Use only relevant sources such as:

- projects;
- source code;
- tests;
- benchmarks;
- coursework;
- professional experience;
- technical documentation;
- reproducible outputs.

## Classification

For each skill, classify evidence as:

- **Strong** — repeated or substantial evidence
- **Moderate** — clear evidence, but limited depth or scope
- **Weak** — indirect or minimal evidence
- **Unsupported** — no reliable evidence

## Rules

- Do not infer competence from a technology being mentioned once.
- Do not equate project dependency lists with demonstrated skill.
- Distinguish usage from mastery.
- Prefer concrete implementation evidence over self-description.
- Identify the strongest supporting project for each skill.

## Output

For every assessed skill provide:

- skill name;
- evidence level;
- supporting evidence;
- strongest supporting project or experience;
- limitation or uncertainty.

Also identify:

- newly demonstrated skills;
- skills whose evidence has strengthened;
- skills that should not yet be claimed prominently.
