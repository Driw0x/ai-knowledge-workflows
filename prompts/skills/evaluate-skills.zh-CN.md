# 评估已展示的能力提示

检查可用的证据，确定哪些技能实际上已被展示。

<a id="evidence-sources"></a>
## 证据来源

仅使用相关来源，例如：

- 项目；
- 源代码；
- 测试；
- 基准测试；
- 课程作业；
- 专业经验；
- 技术文档；
- 可复现的输出结果。

<a id="classification"></a>
## 分类

对于每项技能，将证据分类为：

- **强** - 重复或充分的证据
- **中等** - 明确的证据，但深度或范围有限
- **弱** - 间接或微弱的证据
- **未支持** - 没有可靠的证据

<a id="rules"></a>
## 规则

- 不要仅因某项技术被提及一次就推断具备能力。
- 不要将项目依赖列表等同于展示出的能力。
- 区分使用与精通。
- 优先选择具体的实现证据，而非自我描述。
- 为每项技能识别最强的支持项目。

<a id="output"></a>
## 输出

对于每一个评估过的技能，请提供：

- 技能名称；
- 证据等级；
- 支持性证据；
- 最强支持的项目或经验；
- 局限性或不确定性。

此外识别：

- 新展示出的能力；
- 证据已增强的技能；
- 目前不应突出宣称的技能。
