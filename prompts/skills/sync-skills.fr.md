# Prompts de synchronisation des compétences

Synchroniser les enregistrements de compétences du candidat avec les preuves actuelles relatives au projet, à l'éducation et à l'expérience.

<a id="objective"></a>
## Objectif

Assurer que les affirmations sur les compétences restent en accord avec ce que le candidat peut effectivement démontrer.

<a id="process"></a>
## Processus

1. Lire les enregistrements actuels des compétences.
2. Examiner les projets et l'expérience pertinents.
3. Effectuer une comparaison fondée sur les preuves.
4. Identifier les ajouts, les améliorations, les réductions et les suppressions.
5. Conserver les compétences dont les preuves n'ont pas changé.

<a id="rules"></a>
## Règles

- Ne pas ajouter de compétences non prouvées.
- Ne pas augmenter le niveau d'une compétence sans preuves plus solides.
- Ne pas supprimer une compétence valide simplement parce qu'elle est absente du dernier projet.
- Associer les compétences importantes aux projets qui les démontrent.
- Privilégier des différences minimales.
- Maintenir une terminologie cohérente dans les domaines de carrière, projets et compétences.

<a id="output"></a>
## Sortie

Fournir :

- compétences à ajouter ;
- compétences à renforcer ;
- compétences à conserver inchangées ;
- compétences à réduire ou supprimer ;
- liens ou références basés sur des projets ;
- une justification concise pour chaque modification.

Si une modification est demandée, mettre à jour uniquement les fichiers pertinents des compétences.
