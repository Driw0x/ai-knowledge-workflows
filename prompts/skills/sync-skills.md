# Synchronize Skills Prompt

Synchronize the candidate's skill records with current project, education, and experience evidence.

## Objective

Keep skill claims aligned with what the candidate can actually demonstrate.

## Process

1. Read the current skill records.
2. Inspect relevant projects and experience.
3. Run an evidence-based comparison.
4. Identify additions, upgrades, downgrades, and removals.
5. Preserve skills whose evidence has not changed.

## Rules

- Do not add unsupported skills.
- Do not upgrade a skill level without stronger evidence.
- Do not remove a valid skill simply because it is absent from the newest project.
- Link important skills to the projects that demonstrate them.
- Prefer minimal diffs.
- Keep terminology consistent across Career, Projects, and Skills.

## Output

Provide:

- skills to add;
- skills to strengthen;
- skills to keep unchanged;
- skills to downgrade or remove;
- supporting project links or references;
- a concise rationale for each change.

If modification is requested, update only the relevant skill files.
