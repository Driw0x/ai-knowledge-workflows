<a id="synchronize-skills-prompt"></a>
# 同步技能提示

将候选人的技能记录与当前项目、教育背景和工作经验证据进行同步。

<a id="objective"></a>
## 目标

确保技能声明与候选人实际能够展示的内容保持一致。

<a id="process"></a>
## 流程

1. 读取当前的技能记录。
2. 检查相关的项目和工作经验。
3. 基于证据进行对比分析。
4. 识别新增、升级、降级和删除的技能。
5. 保留证据未发生变化的技能。

<a id="rules"></a>
## 规则

- 不得添加未经支持的技能。
- 不得在缺乏更强证据的情况下提升技能等级。
- 不得因为最新项目中未出现而简单移除一个有效技能。
- 将重要技能与展示该技能的项目关联起来。
- 优先选择最小差异。
- 在职业经历、项目和技能之间保持术语一致性。

<a id="output"></a>
## 输出

提供：

- 需要新增的技能；
- 需要加强的技能；
- 保持不变的技能；
- 需要降级或移除的技能；
- 支持性的项目链接或参考；
- 每项变更的简要理由。

如果需要修改，请仅更新相关的技能文件。
